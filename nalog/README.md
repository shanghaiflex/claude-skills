# nalog — скилл Claude Code для 3-НДФЛ в ЛК ФНС

Подача декларации 3-НДФЛ и имущественного вычета в личном кабинете налоговой
(`lkfl2.nalog.ru`) через реальный Chrome под управлением Playwright по CDP.

Скилл написан по следам живой подачи декларации: всё, что здесь описано как ловушка,
там и всплыло — от формы, которая молча теряет объект, до чекбокса, снимающего вычет
без единого сообщения об ошибке.

## Главное правило

ЛК ФНС — React-приложение, вся форма декларации внутри безымянного iframe. Кнопки,
чекбоксы и загрузка файлов **не поддаются программным кликам**: обработчик перехватывает
событие, а форма при этом портится. Поэтому разделение труда жёсткое:

- **агент** — читает экран, считает суммы, заполняет текстовые поля, ведёт по шагам;
- **человек** — входит через Госуслуги, жмёт кнопки, грузит файлы, вводит пароль ЭП.

Продавливать клики (`force`, JS-клик, мышь по координатам) бесполезно и вредно.

## Установка

```sh
git clone https://github.com/shanghaiflex/claude-skills.git
cp -r claude-skills/nalog ~/.claude/skills/
```

Нужен Python с Playwright (скилл рассчитан на venv `~/.claude/tools/playwright/venv`),
`pypdf` для работы с PDF и `tesseract` с русским языковым пакетом — для сканов.

```sh
~/.claude/tools/playwright/venv/bin/python -m pip install playwright pypdf pillow
curl -L -o /opt/homebrew/share/tessdata/rus.traineddata \
  https://github.com/tesseract-ocr/tessdata_fast/raw/main/rus.traineddata
```

## Команды

```sh
PW=~/.claude/tools/playwright/venv/bin/python
NL=~/.claude/skills/nalog/nalog.py

$PW $NL launch                             # Chrome на своём профиле + страница входа ЛК
$PW $NL state                              # жива ли сессия, какой шаг, какие суммы
$PW $NL dump                               # весь экран и все поля со значениями
$PW $NL draft <cardId> --to Документы      # открыть черновик и довести до шага
$PW $NL fill sumExpenses 2000000           # заполнить текстовое поле
$PW $NL receipt <ФН> <ФД> <ФПД> --out dir  # чек ОФД: PDF без шифрования + PNG
$PW $NL ocr договор.pdf --pages 1-7        # прочитать скан (rus)
$PW $NL unzip pkg.zip --out dir            # пакет Росреестра с битыми именами внутри
```

Профиль Chrome отдельный (`~/.claude/tools/playwright/chrome-profile`), пользовательский
не затрагивается. Порт CDP — 9222, меняется через `NL_PORT`.

## Что внутри знаний

`SKILL.md` описывает подробно; коротко самое дорогое:

- упрощённая форма вычета не сохраняет объект — работать только через полную 3-НДФЛ;
- карточка объекта требует заполнить сумму расходов уже после добавления;
- клик по отмеченному чекбоксу вычета снимает его и обнуляет декларацию молча;
- с 2025 года шкала прогрессивная, возврат считается по предельной ставке, а не по 13%;
- чеки ОФД приходят зашифрованными, ЛК отвечает «файл повреждён или защищён»;
- чек восстанавливается по ФН/ФД/ФПД из письма, без доступа к почте;
- пароль к сертификату ЭП не восстанавливается — только отзыв и перевыпуск.

## Оговорка

Скилл помогает заполнить форму, а не заменяет налогового консультанта. Суммы и право на
вычет проверяйте сами: ответственность за поданную декларацию несёт налогоплательщик.
