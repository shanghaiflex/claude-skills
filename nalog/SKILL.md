# 3-НДФЛ в ЛК ФНС через Playwright

ЛК ФНС — React-приложение, у которого **вся форма декларации живёт в безымянном iframe**, а кнопки,
чекбоксы и загрузка файлов не реагируют на программные клики. Отсюда единственно рабочее разделение:
**агент читает, считает и заполняет текстовые поля; человек нажимает кнопки и грузит файлы.**

Попытки продавить кнопку (`force=True`, JS-клик, клик мышью по координатам) не работают — проверено на
десятке вариантов — и при этом **портят состояние формы**. Не продавливать: увидел перехват — отдал шаг
пользователю.

## Команды

```
PW=~/.claude/tools/playwright/venv/bin/python
NL=~/.claude/skills/nalog/nalog.py

$PW $NL launch                      # поднять Chrome на своём профиле, открыть страницу входа ЛК
$PW $NL state                       # сессия жива? какой шаг формы? суммы?
$PW $NL dump                        # текст текущего экрана + все поля ввода со значениями и валидностью
$PW $NL draft <cardId> [--to Документы]   # открыть черновик и довести до шага
$PW $NL fill <id-подстрока> <значение>    # заполнить текстовое поле (суммы — так)
$PW $NL receipt <ФН> <ФД> <ФПД> --out dir # чек ОФД: PDF без шифрования + PNG
$PW $NL ocr <pdf> [--pages 1-7]           # OCR скана (rus), чтобы прочитать договор
```

Профиль Chrome — `~/.claude/tools/playwright/chrome-profile`, свой, не пользовательский. Порт CDP 9222.

## Порядок

1. `launch` → **пользователь входит через Госуслуги**. Вход по ИНН требует пароля, который выдают
   только лично в инспекции; ЭП — отдельная история. Госуслуги — единственный быстрый путь.
2. `state`. Если «сервис авторизации через Госуслуги (ЕСИА) временно недоступен» — это авария на стороне
   ФНС, а не проблема учётки. Лечится ожиданием (часы), не повторными попытками.
3. Собрать факты **до** формы: объект и дату права — из `/lkfl/individual/propertyObjects`, доходы
   подтягиваются в саму декларацию автоматически.
4. Вести форму: агент заполняет суммы, пользователь жмёт «Добавить», «Выбрать файлы», «Отправить».
5. Перед отправкой — сверить шаг «Подтверждение»: там видно сумму вычета и налоговую базу по ставкам.

## Где ЛК молча теряет данные

- **Упрощённая форма вычета (`ndfl3LightDeduction/propertyDeduction`) не сохраняет объект.** Добавляешь
  квартиру — модалка закрывается, в «Сведениях об объектах» пусто, в DOM объекта нет. Воспроизводится в
  чистом обращении. **Использовать полную декларацию** `appeals/3NDFL/3NDFL` — там всё работает.
- **Модалка объекта двухшаговая.** После «Добавить» объект появляется карточкой, внутри которой ещё надо
  заполнить «Сумма расходов на приобретение» — до этого форма показывает красное «Одно из полей расходов
  должно быть больше 0.00», а итог остаётся нулевым. Легко принять за «объект не добавился».
- **Клик по уже отмеченному чекбоксу на шаге «Выбор вычетов» снимает галочку** — и декларация тихо
  становится нулевой: «Сумма налоговых вычетов 0,00», возврат 0 ₽, при этом карточка объекта и суммы
  на месте, ошибок нет. Перед кликом всегда проверять `is_checked()`. Эта ошибка обнаруживается только
  на шаге «Подтверждение».
- **Сессия протухает за полчаса-час.** Черновик при этом цел: открывается по
  `appeals/3NDFL/3NDFL?cardId=<номер>`, данные и вложенные файлы сохраняются.

## Навигация

- Прямой `goto` рендерит `propertyObjects`, `declarations`, `3NDFL/3NDFL?cardId=…`. Разделы `elk/income`
  и подобные по прямой ссылке отдают пустую страницу — туда только кликом из меню.
- Форма в iframe: `[f for f in page.frames if f != page.main_frame][0]`. `page.inner_text("body")` пуст —
  это нормально, читать надо фрейм.
- Кастомные селекты (`.m-select`) — скрытый input плюс видимая обёртка; кликать по обёртке, `Escape`
  не закрывает список, а **сбрасывает выбор**.
- Текстовые поля (суммы, номера) обычным `fill()` заполняются нормально — это единственное, что
  автоматизируется надёжно.

## Документы

Форма принимает pdf, png, jpg, jpeg, tif, tiff; 10 Мб файл, 20 Мб всего.

- **Чеки ОФД зашифрованы** (`PdfReader.is_encrypted == True`) — ЛК отвечает «файл повреждён или защищён».
  Лечится `decrypt("")` + перезапись через `PdfWriter`, но надёжнее приложить PNG.
- **Чек восстанавливается из письма** без доступа к почте: в письме OFD.RU есть ФН, ФД и ФПД, по ним
  `https://check.ofd.ru/rec/<ФН>/<ФД>/<ФПД>` отдаёт настоящий чек с QR и отметкой «передан в ФНС».
- **Пакет Росреестра после регистрации** приходит письмом от застройщика архивом: там зарегистрированный
  ДКП, выписки ЕГРН и кредитные договоры с файлами подписей. Имена внутри zip в битой кодировке —
  распаковывать по порядку и опознавать по содержимому.
- Сканы без текстового слоя читаются `tesseract -l rus` (языковой пакет: положить `rus.traineddata`
  из `tessdata_fast` в `/opt/homebrew/share/tessdata/`, ставить весь `tesseract-lang` не нужно).
- Вложения Gmail скачиваются из `span[download_url]` через `page.request.get` с куками вкладки. Поиск в
  Gmail применяется только после `reload()` — смена одного хеша в URL ничего не делает.

## Счёт

Вычет — сумма, уменьшающая базу; возврат — деньги. **С 2025 года шкала прогрессивная**, и возврат идёт
по предельной ставке налогоплательщика, а не по 13%: 13% до 2,4 млн, 15% до 5 млн, 18% до 20 млн,
20% до 50 млн, 22% выше. Для дохода в полосе 18% вычет 2 млн даёт не 260 000, а **360 000 ₽**.

- Основной вычет: лимит 2 млн на человека один раз в жизни, остаток переносится на следующие годы.
- Проценты по ипотеке: отдельный лимит 3 млн, только по одному объекту, **нужна справка банка об
  уплаченных процентах** — расчёт по графику ФНС не принимает. В поле идёт сумма за все годы.
- В строку «Сумма расходов на приобретение» можно ввести хоть полную цену: ЛК всё равно возьмёт в расчёт
  не больше 2 млн — «Стоимость всех объектов» сама обрежется до лимита (проверено вводом суммы заметно выше).
- Год вычета: для ДДУ — дата акта приёма-передачи, для купли-продажи — **дата регистрации права**.
- Заявление на возврат уже внутри декларации, отдельно подавать не надо.

## Что делает только человек

Вход через Госуслуги и любые капчи. Кнопки «Добавить», «Далее» в модалках, «Выбрать файлы»,
«Загрузить документы», «Отправить». Пароль к сертификату ЭП — задаётся при выпуске, **не
восстанавливается**; если забыт, сертификат отзывают и выпускают новый (минуты-полчаса), черновик при
этом не страдает.

Статусы после отправки: «Ожидает отправки» → «Получено» (принята инспекцией) → камеральная проверка
до 3 месяцев → деньги в течение месяца после неё.
